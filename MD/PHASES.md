# Phase 1–10 implementation map

1. Foundation — auth, profiles, business, members, RLS, responsive shell.
2. Core business — customers, products, orders, payments, expenses, inventory.
3. Financial automation — balances, installment schema, quotes, invoices, receipts, calculations.
4. Intelligence — dashboard metrics, profit/margin, stock and customer signals, calculators.
5. Communication — WhatsApp/email notification surfaces and message-ready UI.
6. Customer platform — customer identity, cross-business purchase history and balances.
7. Marketplace — public business discovery, profiles, categories, reviews, following, featured placement.
8. Monetization — plans, subscriptions, featured listings.
9. Payments — online payment adapter boundary and payment confirmation flow.
10. Partnerships — organizations, consent records, partner services and future API boundary.

The repository contains the database foundation and web UI for all ten areas. External provider credentials and production contracts must be connected in the deployment environment rather than hard-coded into the source.
